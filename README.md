# Vantage releases

Downloads for **Vantage**, a VALORANT companion app.

- **Vantage Link** is the small Windows app that installs Vantage on your iPhone and keeps it renewed, and can hide your
  VALORANT status from friends. Download `vantage-link.exe` from the [latest release](../../releases), run it, and follow
  the steps. It starts with Windows and updates itself.
- The iPhone app itself is published here as `ios-v…` releases. You don't download those by hand: Vantage Link fetches
  the newest one and installs it on your phone.

Every file here is signed with the project's release key, and Vantage Link refuses anything that isn't.

The source code is private. This repository only holds release files and the workflows that build them.
